Random LP Team — PWA

Файлы:
- index.html — приложение
- manifest.json — параметры PWA
- sw.js — офлайн-кэш
- icon-192.png / icon-512.png — иконки
- apple-touch-icon.png — иконка iOS
- favicon.png — favicon

Публикация:
1. Создайте публичный GitHub-репозиторий random-lp-team.
2. Загрузите содержимое этой папки в корень репозитория.
3. Settings → Pages → Deploy from a branch.
4. Branch: main, Folder: / (root).
5. Save.
6. Откройте выданную GitHub Pages ссылку.
